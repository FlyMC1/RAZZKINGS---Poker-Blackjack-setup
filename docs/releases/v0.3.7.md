# RAZZKINGS v0.3.7 - Windows Setup Reliability

Release date: 2026-06-08

## Highlights

- Fixed the Windows first-time setup launcher so it gives immediate visible diagnostics instead of appearing idle.
- `setup-public-host-windows.cmd` now:
  - shows the project folder before setup starts,
  - verifies the PowerShell setup script exists,
  - verifies Windows PowerShell is available,
  - explains when the full project zip must be extracted first,
  - runs setup in automatic mode by default.
- `scripts/windows/setup-public-host.ps1` now supports `-Auto` mode for first-time setup.
- Updated public-hosting docs to describe the expected setup banner/output and compressed-zip extraction requirement.

## Expected Windows Behavior

When you run `setup-public-host-windows.cmd`, it should immediately show the RAZZKINGS setup banner and begin checking/installing Node.js, cloudflared, project dependencies, and the Desktop shortcut.

If the window opens but does not show setup text, extract the full project zip first, then run the setup file from the extracted folder.

## Validation

- `npm run build` passed.
- Windows PowerShell execution could not be run inside the Linux dev container.
