# RAZZKINGS v0.3.12 - Startup Diagnostics

Release date: 2026-06-10

## Fixes

- Added persistent startup diagnostics logging in Electron main process.
- Added crash logging for uncaught exceptions, unhandled rejections, renderer process exits, and child process exits.
- Added a visible error dialog for fatal startup failures.

## Log Location

- Windows installed app logs are written to `%APPDATA%\\RAZZKINGS\\logs\\startup.log`.

## Validation

- `node --check electron/main.js` passed.
- `npm run build` passed.
