# RAZZKINGS v0.3.11 - Startup Reliability Fix

Release date: 2026-06-10

## Fixes

- Fixed a startup deadlock where the app could appear to do nothing if local server startup failed.
- Electron now opens the app window even when background server bootstrap has an error.
- Server startup now rejects on listen errors instead of hanging indefinitely.

## Validation

- `node --check server/index.js` passed.
- `node --check electron/main.js` passed.
- `npm run build` passed.
