# RAZZKINGS v0.3.14 - Reliable Installer Mode

Release date: 2026-06-11

## Fixes

- Switched Windows release packaging from `nsis-web` to standard `nsis` installer.
- Installer now uses assisted mode (`oneClick: false`) so installation progress is visible.
- This avoids silent web-installer dependency/download issues on some Windows systems.

## Expected Behavior

- Running the setup EXE should always show installation UI.
- App files are installed from the installer package directly.
- Desktop shortcut launch remains the same debug-first flow for startup diagnostics.

## Validation

- Windows NSIS setup artifact generated in `release/`.
