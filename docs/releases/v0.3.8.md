# RAZZKINGS v0.3.8 - Host Status Indicator

Release date: 2026-06-08

## Highlights

- Added a fixed top-right app badge showing hosting availability:
  - Green **Live public** when outside-network hosting is active through a public HTTPS URL.
  - Orange **LAN only** when the app is available only on the local/local-network address.
  - Red **Host error** when the app cannot reach the local host server.
- Added `/api/host-status` so the app can report current public/LAN/error state.
- Hardened `start-public-host.cmd` so Windows users see immediate diagnostics instead of an apparently idle window.
- `start-public-host.cmd` now checks for:
  - extracted project files,
  - Node.js,
  - npm,
  - the public host launcher script.
- Updated docs with badge meaning and public-host launcher troubleshooting.

## Expected Hosting Behavior

When public hosting is launched with Cloudflare, the app should switch to green **Live public** once `PUBLIC_BASE_URL` is active.

If the launcher window appears idle, use the latest `RAZZKINGS-public-host-project-0.3.8.zip`, extract it fully, and run `start-public-host.cmd` from the extracted folder.

## Validation

- `npm run build` passed.
- `node --check server/index.js` passed.
- `/api/host-status` smoke test returned LAN status locally.
