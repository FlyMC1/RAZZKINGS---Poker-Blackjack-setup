# RAZZKINGS v0.3.9 - One-Click Windows Setup

Release date: 2026-06-09

## Highlights

- Added a branded Windows web installer with the RAZZKINGS logo as the installer icon.
- The installer now creates a Desktop shortcut that launches the installed public-host setup flow from the device files.
- The install process now starts the hosting launcher automatically after setup completes.
- Packed the launcher and support scripts into the app bundle so the installed setup works without needing the repo checkout.

## Expected Setup Behavior

After running the Windows web installer, you should get a Desktop shortcut named RAZZKINGS.

Launching that shortcut should start the installed public-host flow directly from the device files and bring up the Cloudflare-based hosting workflow automatically.

- `npm run dist` passed.
- `npx electron-builder --win --x64 --dir` passed.
