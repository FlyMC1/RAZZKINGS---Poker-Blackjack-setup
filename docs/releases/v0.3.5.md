# RAZZKINGS v0.3.5 - Multi-Mode Reliability and Tournament Flow

Release date: 2026-06-08

## Highlights

- Added deterministic seeded outcomes for:
  - Raffle Wheel spins
  - Duck Race finish ordering and winner selection
- Added replay retention policy with automatic expiry and cleanup.
- Improved Card Games tournament flow:
  - hand progression now supports explicit **Deal next hand** after round completion,
  - tournament continues until one player has chips remaining,
  - host can still manually end and save replay.
- Removed duplicate card overlay in Card Games table view.

## Replay Retention

- Replays now auto-expire based on `REPLAY_RETENTION_DAYS`.
- Default retention is **30 days** if not configured.
- Cleanup runs automatically during server lifecycle and replay operations.

## Module Flow Improvements

- Raffle and Duck modes now use server-backed module state updates for entries, jumble actions, and winner events.
- Module session finish endpoint now saves replay payloads with retention metadata.

## Notes

- This release focuses on fairness/auditability and long-session host control stability.
