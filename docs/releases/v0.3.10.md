# RAZZKINGS v0.3.10 - Installer Launch Fix

Release date: 2026-06-10

## Fixes

- Fixed the Windows installer shortcut target so it launches the installed `RAZZKINGS.exe` directly.
- Added packaged `--public-host` launch support in Electron main process.
- The app now starts Cloudflare tunnel mode from the installed executable when launched by the installer shortcut.
- Removed dependency on `start-public-host.cmd` being present at `$INSTDIR`.

## Validation

- `node --check electron/main.js` passed.
- `npm run build` passed.
