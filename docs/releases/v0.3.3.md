# RAZZKINGS v0.3.3 - Windows One-Click Public Host Setup

Release date: 2026-06-08

## Highlights

- Added a guided Windows setup wizard that prompts through each install step.
- Added automatic prerequisite installation support for:
  - Node.js LTS
  - cloudflared
- Added automatic project dependency install (`npm install`) during setup.
- Added automatic Desktop shortcut creation for fast launch.
- Added one-click public host launcher flow docs and command references.

## New Setup Flow (Windows)

1. Run `setup-public-host-windows.cmd`.
2. Follow prompts to install/check prerequisites and dependencies.
3. Use Desktop shortcut **RAZZKINGS Public Host** to launch public hosting sessions.
4. Create table and share generated links/QR for outside-network players.

## Added Commands

- `npm run setup:windows` - guided Windows setup wizard.
- `npm run host:public:oneclick` - starts tunnel, captures URL, launches app with `PUBLIC_BASE_URL`.

## Notes

- This release focuses on onboarding and outside-network hosting startup reliability on Windows.
- Existing gameplay and UI updates from prior releases remain unchanged in this patch.
