# RAZZKINGS v0.3.13 - PowerShell Debug Launcher

Release date: 2026-06-11

## Fixes

- Replaced the installer debug shortcut from `cmd` wrapper to a PowerShell launcher for more reliable execution on Windows.
- The installer now writes `start-razzkings-debug.ps1` in the install folder and launches it automatically after install.
- Desktop shortcut now targets PowerShell with explicit `-ExecutionPolicy Bypass` and `-File` arguments.
- Debug launcher writes a guaranteed Desktop log at `%USERPROFILE%\\Desktop\\razzkings-launch.log` before and during app launch.

## Validation

- Windows installer artifacts generated in `release/nsis-web`.
