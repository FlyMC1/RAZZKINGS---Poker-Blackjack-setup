# RAZZKINGS v0.3.15 - Offline Installer, Direct Launch

Release date: 2026-06-16

## Fixes

- Switched Windows packaging to a standard offline NSIS installer only.
- Removed the web-installer target from Windows builds.
- Dropped the custom PowerShell launch script from the installer path.
- The Desktop and Start Menu shortcuts now launch the installed app directly.
- The app starts in local/LAN mode by default after installation.

## Expected Behavior

- Running the setup EXE should always show the normal Windows setup wizard.
- The installer installs the bundled app files directly from the EXE.
- Launching the shortcut opens RAZZKINGS in local mode without any extra setup.

## Validation

- Windows NSIS setup artifact should be generated as `RAZZKINGS-Setup-0.3.15.exe`.
