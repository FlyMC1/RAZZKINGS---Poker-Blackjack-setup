# RAZZKINGS v0.3.6 - Visual Game Upgrade

Release date: 2026-06-08

## Highlights

- Added single-player Blackjack repeat-hand testing support.
- Improved Card Games table visibility with generated SVG player silhouettes.
- Kept public table cards visible only where appropriate:
  - Blackjack visible cards show on the table.
  - Private poker cards remain in the player's bottom hand area.
- Replaced Raffle Wheel placeholder with a generated SVG segmented wheel.
- Added deterministic raffle spin animation metadata so the wheel lands on the server-selected winner.
- Added a non-sexual animated show presenter beside the wheel.
- Replaced Duck Race placeholder with a generated SVG figure-8 water track.
- Added generated SVG duck racers with bobbing, jumping, spinout-style motion, and splash/foam effects.
- Added duck race event metadata for deterministic visual playback.

## Technical Notes

- Uses React + generated SVG + CSS animations.
- No heavy game engine added.
- No unknown-license public repo assets or copied code added.

## Validation

- `npm run build` passed.
